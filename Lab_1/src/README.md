# Unit Converter (Python)

A tiny, beginner-friendly Python project that converts **length**, **weight**, and **time**. Perfect for practicing Python basics and common Git commands.

## ✨ Features
- Length: meters → kilometers, centimeters, millimeters
- Weight: kilograms → grams, pounds
- Time: hours → minutes, seconds
- Clear menu-driven CLI

## 📦 Requirements
- Python 3.8+ (works on macOS, Linux, Windows)
- No third-party packages required

## 🚀 Setup
```bash
# 1) Create a folder and add the script
mkdir unit-converter && cd unit-converter
# Save `unit_converter.py` into this folder

# 2) (Optional) Initialize Git
git init
git add unit_converter.py
git commit -m "Add unit converter script"
